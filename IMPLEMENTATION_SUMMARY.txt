2️⃣ Rate Limiting Implementation
   📄 File: routes/api.php (UPDATED)
   ─────────────────────────────────────────────────────────────
   ✓ Added Limit import: Illuminate\Cache\RateLimiting\Limit
   ✓ Configured rate limiter with dual-tier system:

      TIER 1 - Authenticated Users:
      • 60 requests per minute
      • Identified by user ID from Sanctum token
      • Allows power users higher quota

      TIER 2 - Anonymous Users:
      • 5 requests per minute
      • Identified by IP address
      • Prevents brute force and DDoS

   ✓ Applied throttle:api middleware to all /api/v1/* routes
   ✓ Returns 429 (Too Many Requests) when limit exceeded

   BENEFITS:
   • Protects API from abuse
   • Fair resource allocation
   • Prevents brute force attacks
   • Easy to adjust limits per environment

🎓 KEY CONCEPTS EXPLAINED

CORS (Cross-Origin Resource Sharing)
────────────────────────────────────
• Allows browser to fetch from different domain
• Whitelist approach: only allowed origins can access
• Preflight requests cached for performance

Rate Limiting (Throttling)
────────────────────────────────────
• Restricts number of requests in time period
• Prevents abuse, DDoS, brute force
• Different limits for authenticated vs anonymous
• Returns 429 status when exceeded
